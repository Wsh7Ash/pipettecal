# Uniqueness — pipettecal

## Closest alternatives
Online gravimetric calculators, Artel PCS.

## Meaningful differences
Open-source CLI producing a verifiable certificate with embedded input and an
independent re-derivation command; stdlib only.

## Unique mechanism
Buoyancy-corrected per-replicate volume + statistics + pass/fail, with an
embedded-input certificate and independent verifier.

## Remaining uncertainties
Water density polynomial is approximate; not a certified procedure.
